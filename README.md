# CSV Data Cleaner & Report Tool

A Python automation tool that cleans CSV data and generates summary statistics.

## Features
- Removes rows with missing or invalid data
- Converts data to correct types
- Outputs a cleaned CSV file
- Prints summary statistics (average, min, max)

## Usage
1. Place your CSV file in the `data` folder
2. Run `csv_cleaner.py`
3. Cleaned file is saved to `output/cleaned_output.csv`

## Use Case
Useful for cleaning survey results, student data, or business records before analysis.
